# Spike 1.3 - preset TTFT with a ~2k-token cached prefix

Goal: measure time-to-first-token of each LLM preset (Claude, DeepSeek, Groq,
Cerebras, OpenRouter, Ollama) with a ~2k-token cached prefix, p50/p90 over N
requests, to pick the default "fast" vs "deep" presets (design D6) and set the
SLOW health threshold.

## How to run

On a machine with network and the provider keys set (not the sandbox). Only
providers whose key env is present are measured:

```
ANTHROPIC_API_KEY=... DEEPSEEK_API_KEY=... GROQ_API_KEY=... CEREBRAS_API_KEY=... \
  node openspec/changes/interview-assistant-mvp/spikes/spike-1.3.mjs
```

- `REQUESTS=20` by default; override via `REQUESTS=...`.
- Per-provider model override: `CLAUDE_MODEL`, `DEEPSEEK_MODEL`, `GROQ_MODEL`,
  `CEREBRAS_MODEL`, `OPENROUTER_MODEL` (OpenRouter also needs its model set).
- Ollama (local) is not in the key-gated list; add it by hand if a local server
  is running.
- The request shapes mirror `src/main/llm/adapters/http.ts` exactly. Anthropic
  sends the prefix as a `cache_control: ephemeral` system block to exercise prompt
  caching; OpenAI-compatible providers cache implicitly if at all. A summary is
  written to `spikes/results-1.3.json`.

## Results

Partial run 2026-11-27 (Linux, Node v22.22.3, `NODE_USE_ENV_PROXY=1` so undici
routes through the sandbox proxy). Only DeepSeek has a key on this machine, so the

with their keys (Groq, Cerebras, OpenRouter) / local server (Ollama) / Anthropic

### Decisions (preliminary - DeepSeek only)

- Default fast preset (lowest p50, acceptable quality): **deepseek** so far
  (p50 610 ms, tight 480-942 ms spread, 20/20 ok). Confirm against Groq/Cerebras,
  which are usually faster, before locking the default.
- Default deep preset: undecided - needs the claude API presets measured.
- SLOW health threshold (ms) from the p90 spread: DeepSeek p90 is 732 ms; a 1500 ms
  threshold (~2x the measured p90) leaves headroom without flagging normal jitter.
  Revisit once the slower presets have numbers.
- Any provider dropped: none yet.

### Sandbox note

Node's `fetch` (undici) does not read `HTTP(S)_PROXY` on its own, so the first run
failed with `fetch failed` while `curl` reached the host. Setting
`NODE_USE_ENV_PROXY=1` makes undici's `EnvHttpProxyAgent` use the env proxy. Not
needed outside the sandbox.

### Cross-check with spike 1.4

The subscription path (spike 1.4) measured ~3160 ms p50 on opus-5-5 + thinking at
~$0.25/req - too slow/costly for live hints. Compare against the API presets here
to decide whether the subscription is a fallback only.
