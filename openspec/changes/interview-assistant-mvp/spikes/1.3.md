# Spike 1.3 - preset TTFT with a ~2k-token cached prefix

Goal: measure time-to-first-token of each LLM preset (Claude, DeepSeek, Groq,
Cerebras, OpenRouter, Ollama) with a ~2k-token cached prefix, p50/p90 over N
requests, to pick the default "fast" vs "deep" presets (design D6) and set the
SLOW health threshold.

## How to run

On a machine with network and the provider keys set (not the sandbox). Only
providers whose key env is present are measured:

```
ANTHROPIC_API_KEY=... DEEPSEEK_API_KEY=... GROQ_API_KEY=... CEREBRAS_API_KEY=... \
  node openspec/changes/interview-assistant-mvp/spikes/spike-1.3.mjs
```

- `REQUESTS=20` by default; override via `REQUESTS=...`.
- Per-provider model override: `CLAUDE_MODEL`, `DEEPSEEK_MODEL`, `GROQ_MODEL`,
  `CEREBRAS_MODEL`, `OPENROUTER_MODEL` (OpenRouter also needs its model set).
- Ollama (local) is not in the key-gated list; add it by hand if a local server
  is running.
- The request shapes mirror `src/main/llm/adapters/http.ts` exactly. Anthropic
  sends the prefix as a `cache_control: ephemeral` system block to exercise prompt
  caching; OpenAI-compatible providers cache implicitly if at all. A summary is
  written to `spikes/results-1.3.json`.
